About us

A shop built around how people actually buy

{{ site_name }} is a working demonstration of a complete e-commerce application - built from scratch with Flask, MySQL and plain HTML, CSS and JavaScript.

What this project is

This is a portfolio project, not a real shop. Nothing is charged and no order is ever shipped. Its purpose is to show how a full online store is put together: a database designed properly, pages that work without JavaScript, and security that is taken seriously rather than bolted on afterwards.

Everything on the site is real working code. The search really queries MySQL, the cart really checks stock, and checkout really writes a row into the orders table inside a database transaction.

How it is built

  • ✓ Backend - Python Flask with 27 routes
  • ✓ Database - MySQL, 6 related tables
  • ✓ Frontend - HTML5, CSS3 and vanilla JavaScript, no framework
  • ✓ Security - hashed passwords, CSRF tokens, parameterised queries, admin authorisation
  • ✓ Tests - 83 automated end-to-end checks
